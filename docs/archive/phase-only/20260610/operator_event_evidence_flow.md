# Operator: Event Evidence Flow

R3 standardizes how an event asks for snapshot and clip evidence.

## Flow

```text
Savant / face-worker
  -> Redis security.events
  -> event-worker
  -> PostgreSQL events
  -> evidence_tasks
  -> security.clip_tasks or media-worker / clip-worker
  -> snapshot.jpg / clip.mp4 / metadata.json
  -> events.snapshot_path / events.clip_path / events.media_status
```

The event-worker consumes one `SecurityEvent` contract for all algorithms. It
does not branch into a different event format per algorithm.

## Media Paths

Preferred output:

```text
/data/video-analytics/media/events/YYYY/MM/DD/<event_id>/metadata.json
/data/video-analytics/media/events/YYYY/MM/DD/<event_id>/snapshot.jpg
/data/video-analytics/media/events/YYYY/MM/DD/<event_id>/raw_clip.mp4
```

`raw_clip.mp4` is the canonical production evidence video. `annotated_clip.mp4`
is optional/on-demand for debug or report export and is not generated by
default. The frontend should render dynamic overlays from `metadata.json`.

If that root is not writable, fallback to `./tmp` is allowed only when
`storage_fallback_used=true` is recorded explicitly.

## Debug Sinks

`video-file-sink` and `metadata-sink` are debug/development sinks. They are not
production evidence, do not enter the evidence API, and should not run as
long-lived production defaults without retention limits.

Debug sink output should be isolated from event evidence, for example:

```text
/data/video-analytics/media/debug/video-file-sink/
/data/video-analytics/media/debug/metadata-sink/
```

## Evidence Policy

Each event may set:

```json
{
  "snapshot_required": true,
  "clip_required": true,
  "pre_seconds": 5,
  "post_seconds": 10
}
```

If neither snapshot nor clip is required, no evidence task is created.

## Current R3 Scope

R3 creates the contract and the database/API shape. Debug smoke outputs are not
production evidence. Full production clip generation remains a later
Replay/NVR-backed media-worker task.

Retention defaults before long-running media generation:

```text
retention_days = 7
max_total_gb = 500
max_camera_gb = 50
min_free_disk_percent = 15
delete_oldest_first = true
```

Cleanup must delete debug sink output first, then expired evidence media. It
must never delete DB rows such as `events`, `face_observations`, or
`match_results`; after media removal it should mark media as `media_expired` or
`media_deleted`.

R3 does not change the Savant module pipeline and does not run performance
tests. Performance testing is scheduled after the event and evidence trunk is
stable.
