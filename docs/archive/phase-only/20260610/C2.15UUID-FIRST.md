Core objective:

Fix post-Savant evidence anchor selection so Replay job creation is UUID-first and PTS-verified.

Final invariant:

Replay anchor_keyframe must come from the event/record_request keyframe UUID family, not from post-window PTS lookup.

Definitions:

* event_frame_uuid = the actual alarm frame UUID.
* event_frame_pts = the alarm frame PTS.
* anchor_keyframe_uuid = the Replay keyframe UUID used to create the Replay job.
* anchor_keyframe_pts = PTS of anchor_keyframe_uuid.
* previous_keyframe_uuid / keyframe_uuid from the alarm frame metadata are the preferred source of anchor_keyframe_uuid.
* post_window_frame_uuid / post_window_frame_pts are completeness proof only.
* start_window_frame_uuid / start_window_frame_pts are coverage/crop helper only.
* PTS is for offset, requested_start_pts/requested_end_pts, duration, crop, and verification only.
* event_ts_ms, Redis publish time, DB created_at, wall clock must not be used as evidence visual anchor.

Hard rules:

1. Replay job payload anchor_keyframe must equal record_request.anchor_keyframe_uuid when provided.

2. record_request.anchor_keyframe_uuid must be derived from alarm-frame metadata:

   * previous_keyframe_uuid preferred
   * otherwise keyframe_uuid
   * never post_window_frame.keyframe_uuid
   * never start_window_frame.keyframe_uuid unless it is exactly the same UUID already provided by the event

3. event_frame_uuid must not be used as Replay anchor_keyframe unless the event frame itself is proven to be a keyframe.

4. post-window frame annotation is only a proof that event_frame_pts + post_seconds has reached the same source/time domain. It must not replace anchor_keyframe_uuid.

5. start-window keyframe/frame annotation is only for coverage/crop diagnostics. It must not replace anchor_keyframe_uuid.

6. keyframe_pts / anchor_keyframe_pts is a calculation field, not the identity anchor.
   If anchor_keyframe_uuid exists but anchor_keyframe_pts is missing:

   * first try to recover anchor_keyframe_pts from frame annotation with the same anchor_keyframe_uuid
   * if impossible, fail closed with missing_anchor_keyframe_pts
   * do not silently substitute post-window or start-window keyframe

7. If anchor_keyframe_uuid is missing:

   * only then may clip-worker call Replay keyframes/find
   * the result must be verified by source_id and PTS window
   * if verification fails, fail closed
   * do not use DB created_at, Redis publish time, or wide PostgreSQL query as fallback

8. Existing dirty worktree must not be cleaned or reset.
   Only edit task-relevant files.
   Do not touch unrelated WIP files.
