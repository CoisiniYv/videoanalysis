# Midterm Web 操作台使用指南

## 访问地址

启动系统后，打开浏览器访问：

```
http://127.0.0.1:8090/operator
```

## 界面功能

### 1. 摄像头管理（默认页面）

**功能：**
- 查看已接入的摄像头列表
- 添加新摄像头
- 编辑摄像头配置（名称、RTSP 地址、站点、位置）
- 启用/停用摄像头
- 配置告警策略（冷却时间）

**操作步骤：**

#### 添加摄像头
1. 点击右上角 **"新增"** 按钮
2. 填写表单：
   - **摄像头名称**：例如"前门摄像头"
   - **视频地址**：RTSP URL，例如 `rtsp://192.168.1.100:554/stream1`
   - **站点**：可选，例如"一号楼"
   - **位置**：可选，例如"主入口"
   - **启用**：勾选后立即生效
3. 点击 **"保存"** 按钮

#### 修改摄像头
1. 在左侧列表点击要修改的摄像头
2. 右侧表单会显示当前配置
3. 修改需要的字段
4. 点击 **"保存"** 按钮

#### 启用/停用摄像头
1. 选择目标摄像头
2. 点击 **"启用"** 或 **"停用"** 按钮
3. 或者直接取消勾选 **"启用"** 复选框后保存

#### 配置告警策略
1. 选择摄像头后，在"告警策略"区域
2. 设置 **"告警冷却时间（秒）"**：同一位置多久内不重复告警
3. 点击 **"保存"** 按钮

---

### 2. 人员与人脸（第二个标签）

**功能：**
- 查看已注册人员库
- 注册新人员和人脸照片
- 为已有人员追加人脸照片
- 查看人脸图库和注册结果

**操作步骤：**

#### 注册新人员
1. 点击顶部 **"人员与人脸"** 标签
2. 在中间"人脸注册"面板：
   - 确保 **"新人员"** 按钮高亮
   - 点击 **"图片"** 选择人脸照片（支持 JPG/PNG/BMP/WEBP）
   - 填写 **"人员编号"**：唯一标识，例如"EMP001"
   - 填写 **"姓名"**：例如"张三"
   - 填写 **"描述"**（可选）：例如"保安部"
3. 点击 **"开始注册"** 按钮
4. 注册结果会显示在右侧"注册回执"区域

#### 为已有人员追加照片
1. 在左侧人员列表点击目标人员
2. 点击 **"追加到当前人员"** 按钮（会变成高亮）
3. 选择新照片
4. **不需要修改"人员编号"和"姓名"**（会自动保留）
5. 点击 **"开始注册"** 按钮

#### 搜索人员
1. 在左侧顶部搜索框输入姓名或人员编号
2. 列表会自动过滤

#### 查看人脸图库
1. 点击左侧人员列表中的人员
2. 右侧"人脸图库"区域会显示该人员所有已注册的人脸照片缩略图

---

### 3. 告警证据（第三个标签）

**功能：**
- 查看所有告警录像证据
- 按类型筛选（名单布控、周界入侵、行为异常、聚集风险）
- 按摄像头或人员筛选
- 播放原始录像
- 查看人脸框、关键点和识别结果标注
- 复核证据有效性

**操作步骤：**

#### 查看告警列表
1. 点击顶部 **"告警证据"** 标签
2. 中间面板显示告警证据列表，包含：
   - 告警类型
   - 摄像头名称
   - 时间
   - 录像状态

#### 筛选告警
1. 点击左侧 **告警分类** 按钮：
   - **全部**：显示所有告警
   - **名单布控**：人脸识别命中告警
   - **周界入侵**：入侵检测告警
   - **行为异常**：徘徊、奔跑、跌倒等
   - **聚集风险**：人群聚集告警
2. 或在筛选字段输入：
   - **摄像头**：摄像头名称或编号
   - **人员**：姓名或人员编号

#### 播放证据录像
1. 在证据列表中点击一条告警
2. 右侧视频播放器会加载原始录像
3. 画面上会自动叠加：
   - **蓝色框**：人员框
   - **绿色框**：已识别人脸
   - **黄色框**：未识别人脸
   - **关键点**：人体姿态关键点
   - **标签**：人员姓名或 ID

#### 控制画面标注
在"画面标注"区域可以切换显示：
- ☑ **显示人员框**
- ☑ **显示命中人脸**
- ☑ **显示未识别人脸**
- ☑ **显示关键点**
- ☑ **显示标签**

#### 查看事件信息
右下角"事件信息"卡片显示：
- 告警类型
- 摄像头名称
- 报警时间
- 录像状态

#### 查看识别摘要
右下角"识别摘要"卡片显示：
- 标注数量
- 人脸数量
- 命中人脸数量
- 未识别人脸数量

## 顶部概览面板

主界面顶部始终显示系统概览：

- **摄像头**：已登记视频源总数
- **启用中**：正在参与调度的摄像头数
- **人员**：已登记身份总数
- **人脸图片**：已入库照片总数
- **告警证据**：可复核录像总数

这些数据会在切换标签时自动刷新。

## 常见问题

### Q1: 打不开 Web 界面？
**A:** 检查服务是否启动：
```bash
bash scripts/midterm_health.sh
```
确保 API 服务在 8090 端口监听。

### Q2: 添加摄像头后看不到画面？
**A:**
1. 检查 RTSP 地址是否正确
2. 确保摄像头"启用"复选框已勾选
3. 查看 Savant 日志：
   ```bash
   docker compose -f infra/docker-compose.midterm.yml logs -f savant-security
   ```

### Q3: 注册人脸失败？
**A:** 常见原因：
- 照片中没有检测到人脸
- 照片中有多张人脸（不支持）
- 人脸太小或质量太低
- 人员编号已被其他人使用

查看注册回执中的错误信息。

### Q4: 告警证据列表是空的？
**A:**
1. 确保摄像头已启用并正常工作
2. 确保有检测规则配置（默认已配置）
3. 等待系统检测到事件（可能需要几分钟）
4. 刷新证据列表

### Q5: 视频播放没有标注框？
**A:**
1. 确保"画面标注"区域的复选框已勾选
2. 检查该告警是否真的包含人脸/人员检测结果
3. 查看"识别摘要"中的数量是否为 0

### Q6: 如何删除摄像头或人员？
**A:** 当前版本暂不支持在 Web 界面删除，需要通过 API 或数据库操作。

## 技术细节

- **前端框架**：纯原生 JavaScript（无框架）
- **样式**：自定义 CSS
- **视频播放**：HTML5 `<video>` + Canvas 叠加层
- **API 通信**：RESTful JSON API
- **实时更新**：手动刷新（点击"刷新"按钮）

## 维护操作

### 日常启停
```bash
# 启动
bash scripts/midterm_start.sh

# 检查状态
bash scripts/midterm_health.sh

# 关闭
bash scripts/midterm_stop.sh
```

### 查看日志
```bash
# 所有服务日志
docker compose -f infra/docker-compose.midterm.yml logs -f

# API 服务日志
docker compose -f infra/docker-compose.midterm.yml logs -f api

# Savant 推理日志
docker compose -f infra/docker-compose.midterm.yml logs -f savant-security
```

### 重启单个服务
```bash
docker compose -f infra/docker-compose.midterm.yml restart api
docker compose -f infra/docker-compose.midterm.yml restart savant-security
```
