# 8090 证据页与人员轨迹页布局重做（2026-10-10）

## 现象

8090 的“告警证据”和“人员轨迹”两个页面都使用同一种 筛选 / 列表 / 详情 三栏布局，
视觉上几乎没有区别：

- 证据列表每条是一段用 `|` 拼接的长文字，没有缩略图，类型和状态不易分辨；
- 视频播放区不突出，告警分类是一列整宽按钮，占用大量空间；
- 轨迹页只是另一份图片列表，看不出“这个人去过哪里、按什么顺序”；
- 隐藏的“录像需复核”状态胶囊因 `display: inline-flex` 覆盖 `[hidden]`，始终显示为空胶囊；
- 人脸命中（图片证据）时空的视频播放器仍然显示在图片上方（`video { display: block }`
  覆盖了 `[hidden]`）。

## 范围

只改 8090 静态前端：

```text
services/evidence-viewer/app/static/index.html
services/evidence-viewer/app/static/style.css
services/evidence-viewer/app/static/evidence.js
services/evidence-viewer/app/static/trajectory.js
```

不改 API、数据库、接口参数和 `operator.js`；所有被脚本和 harness 引用的元素 ID、
`window.operatorTrajectory` 接口和查询参数保持不变。

## 改动

### 共享外观

- 新增类型色（`--cat-*`）与摄像头色（`--cam-1..8`）token，浅色和黑夜模式各一套；
- 左侧导航加图标；顶部统计卡改为紧凑的“标签 + 大数字”横排；子导航改为分段控件；
- 卡片圆角、阴影、按钮过渡统一；手机宽度下导航三列并排、统计卡三列并排。

### 告警证据：复核台

- 左侧单栏 sticky 收件箱：彩色分类 chip、两列筛选、分页、按天分组的告警卡片；
- 卡片包含缩略图（有录像时带播放角标）、类型色左边条、告警时间、摄像头、状态 tag；
- 右侧大舞台：类型图标 + 告警标题 + “摄像头 · 报警时间 · 人员”副标题，16:9 播放区，
  单行标注开关 chip，事件信息 / 识别摘要 / 提示三列卡片；
- 选择告警导致列表重绘时保留滚动位置；换页、换分类、刷新时回到顶部。

### 人员轨迹：以人为中心

- 全宽查询条；
- 人员概况：头像（注册主图优先）、本页出现次数、经过摄像头数、最常出现摄像头、最近一次；
- 行动路线：按时间正序，相邻同一摄像头合并为一站并显示次数，最多 12 站，点击站点选中记录；
- 按天分组的时间线：时间、彩色节点、缩略图、相似度条和来源标签；相邻两次间隔 ≥ 30 分钟时
  显示“间隔 X”；
- 右侧 sticky 出现画面：摄像头/时间角标、人脸小图、相似度条、较新/较早按钮，键盘 ↑ ↓ 切换。

同一摄像头在时间线节点、路线站点和画面角标上使用同一颜色（按摄像头 id 稳定取色）。

## 非目标

- 不修改证据查询性能（列表计数和详情查询问题另行处理）；
- 不改变证据分类、默认选择、删除、跳转轨迹等既有行为；
- 不改摄像头、人员、运维、维护页面的结构，只继承共享外观。

  隐藏胶囊不显示、人脸命中跳转轨迹、时间线默认选中、↑ ↓ 切换、较新按钮边界、路线站点选中、

## 回滚

只涉及上述四个静态文件和本文档、`docs/frontend_interface/04_views_and_modules.md`。
回滚即恢复这四个文件；evidence-viewer 静态目录如为挂载方式，无需重建镜像。

## 剩余风险

- `color-mix()` 与 `:has()` 需要 Chromium 111+ / Safari 16.4+ / Firefox 121+；旧浏览器上
  路线圆点光晕和开关 chip 选中底色会退化，但不影响功能；
- 行动路线和统计只基于当前页（最多 50 条）记录，页面文字已标注“本页”。
