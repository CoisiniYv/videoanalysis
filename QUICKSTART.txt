Video Analytics Platform - Quick Start
======================================

1. Start the platform

    bash scripts/midterm_start.sh

   The startup script checks the runtime environment, prepares data directories,
   builds or starts the required services, and prepares the components managed by
   the operator console.

2. Open the operator console

    http://127.0.0.1:8090/operator

   Port 8090 is the normal browser entry point. Internal API and service ports are
   intended for service-to-service communication and diagnostics.

3. Register cameras

   - Open Configuration -> Cameras.
   - Add a camera name and RTSP URL.
   - Configure ROI, algorithms and event rules.
   - For a multi-camera run, configure cameras first and select the desired set
     when starting the runtime.

4. Select a runtime profile

   Reference profiles included in the repository:

   - production_t4_40: 40 streams, A/B 20/20, 4 FPS analysis.
   - local_4090_60:    60 streams, A/B 30/30, 8 FPS analysis.

   Actual capacity depends on GPU, resolution, bitrate, codec settings, event
   density and storage performance.

5. Start the complete pipeline

   In Start & Runtime, select the cameras and launch the complete dual-branch
   runtime. Wait for source convergence and rolling-cache readiness, then verify:

   - expected A/B source counts;
   - continuously updating frames;
   - stable analysis FPS;
   - queues and failures are not continuously increasing;
   - evidence tasks reach completed or explicit terminal states;
   - event evidence and person trajectories are queryable.

6. Register people and faces (optional)

   Use People & Faces in the operator console to create a person and enroll one
   or more clear face images. The complete runtime uses the ROI AdaFace pipeline
   for face embeddings and gallery matching.

7. Health checks

    bash scripts/midterm_health.sh
    bash scripts/runtime/doctor_midterm.sh

   For per-camera evidence reconciliation, see:

    scripts/runtime/report_evidence_camera_ledger.py

8. Stop

   - Stop only the active analysis runtime from the 8090 operator console.
   - Stop the complete stack with:

       bash scripts/midterm_stop.sh
