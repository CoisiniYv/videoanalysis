┌──────────────────────────────────────────────────────────────────────────────┐
│ 第一步：启动系统                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

    bash scripts/midterm_start.sh

    等待服务启动（约 1-3 分钟），看到 "Startup Complete" 后继续。
    新机器首次启动会先检查模型文件和 /data/video-analytics 运行目录。


┌──────────────────────────────────────────────────────────────────────────────┐
│ 第二步：打开 Web 操作台                                                       │
└──────────────────────────────────────────────────────────────────────────────┘

    浏览器访问：http://127.0.0.1:8090/operator

    你会看到一个中文界面，包含三个标签：

    ┌─────────────┬─────────────┬─────────────┐
    │ 摄像头管理   │ 人员与人脸   │ 告警证据     │
    └─────────────┴─────────────┴─────────────┘


┌──────────────────────────────────────────────────────────────────────────────┐
│ 第三步：配置摄像头（必需）                                                     │
└──────────────────────────────────────────────────────────────────────────────┘

    1. 点击 "摄像头管理" 标签（默认已选中）
    2. 点击右上角 "新增" 按钮
    3. 填写表单：
       • 摄像头名称：例如 "前门摄像头"
       • 视频地址：例如 rtsp://192.168.1.100:554/stream1
       • 勾选 "启用" 复选框
    4. 点击 "保存" 按钮

    ✓ 系统会自动开始处理该摄像头的视频流


┌──────────────────────────────────────────────────────────────────────────────┐
│ 第四步：注册人脸（可选）                                                       │
└──────────────────────────────────────────────────────────────────────────────┘

    1. 点击 "人员与人脸" 标签
    2. 在中间面板选择人脸照片
    3. 填写表单：
       • 人员编号：例如 "EMP001"（唯一标识）
       • 姓名：例如 "张三"
    4. 点击 "开始注册" 按钮

    ✓ 注册后系统会自动识别该人员出现在摄像头中


┌──────────────────────────────────────────────────────────────────────────────┐
│ 第五步：查看告警证据                                                           │
└──────────────────────────────────────────────────────────────────────────────┘

    1. 点击 "告警证据" 标签
    2. 等待系统生成告警（可能需要几分钟）
    3. 点击列表中的告警查看录像
    4. 视频会自动叠加人脸框和识别结果

    提示：如果列表为空，说明系统还没检测到异常事件

╔══════════════════════════════════════════════════════════════════════════════╗
║                              关键端口                                         ║
╚══════════════════════════════════════════════════════════════════════════════╝

    8090  →  Web 操作台 & API 服务
    6396  →  Redis 缓存
    8098  →  Replay API（内部/诊断）
    18080 →  Savant metrics（诊断）
    18081 →  analysis-forwarder metrics（诊断）

    日常管理只需要打开 8090 页面；其他端口用于内部链路或诊断。


╔══════════════════════════════════════════════════════════════════════════════╗
║                              故障排查                                         ║
╚══════════════════════════════════════════════════════════════════════════════╝

    问题：无法访问 Web 界面
    解决：
        1. 运行 bash scripts/midterm_health.sh
        2. 检查 API 服务是否在运行
        3. 确认没有端口冲突

    问题：添加摄像头后无画面
    解决：
        1. 检查 RTSP 地址是否正确
        2. 确认摄像头已启用
        3. 查看日志：docker compose -f infra/docker-compose.midterm.yml logs savant-security

    问题：人脸注册失败
    解决：
        1. 确保照片清晰，只有一张人脸
        2. 检查人员编号是否重复
        3. 查看注册回执中的错误提示

系统架构：RTSP 源 → Replay 存储 → Savant 推理 → Redis/PostgreSQL
         → 事件检测 → 录像截取 → 证据生成 → Web 操作台复核

证据生成策略：raw_clip.mov（原始视频）+ annotations.jsonl（标注数据）
